# Seed: core principles

These principles constrain decisions without pretending to describe current implementation.

This file is the target project's author-owned Product Seed. It is separate from the versioned Orrery operating-rules inventory supplied by the toolchain; those portable rules do not become project principles merely because their wording is similar.

1. Current facts must remain distinguishable from plans and aspirations.
2. Important decisions preserve their reasons and history.
3. Completion requires implementation plus validation evidence.
