# PO-CR-025：安装目标边界不得经链接逃逸

这是一个局部、高风险的文件系统安全任务。

加固 Project Orrery 安装器：无论是首次安装、普通重复运行、`--upgrade-tools` 还是 `--dry-run`，只要目标根到任何将要读取、创建、覆盖或备份的目标路径之间存在符号链接、目录联接、reparse point 或其他会把操作导向目标根外部的链接边界，都必须在发生目标写入前失败关闭。

必须保持：

- 正常目录中的首次安装、重复运行、保留作者文件和升级前备份行为不变；
- 已存在的链接文件或链接目录不能被当成普通作者文件读取、覆盖或复制到备份；
- `.project-orrery-backup` 路径本身也受同一边界保护；
- `--dry-run` 必须执行同样的边界检查，并且不能把“没有写入”当作允许越界检查的理由；
- 拒绝结果必须是非零退出码和不含外部文件正文的简洁错误；
- Windows 与 POSIX 都要有明确处理；无法可靠判定某种链接边界时应保守拒绝，而不是跟随。

只修改 RUN CONTRACT 允许的安装器文件。不要添加测试或文档。
