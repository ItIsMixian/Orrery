# 任务 PO-CR-013：可信且可恢复的更新清单缓存

这是一个高风险、发布链路中的局部代码任务。

加固 Project Orrery 更新检查器的远程 release manifest 缓存。网络成功时只能缓存经过现有 Project Orrery manifest 规则验证的有限大小 JSON；网络失败时可以回退到旧缓存，但旧缓存也必须经过相同验证。

必须保持这些行为：

- 远程响应有明确大小上限，不能把无界响应完整读入内存；
- 新缓存使用 UTF-8 和可恢复的原子替换；写入或替换失败不能破坏此前有效缓存，也不能遗留临时文件；
- 非对象、错误项目名、非法版本或损坏 JSON 不能成为 fresh／stale cache；
- `--offline`、`--manifest-file` 和已有兼容性判断的公开行为不被无意改变；
- 错误与 warning 不得回显 manifest URL 中的 query／fragment 敏感信息；
- 本任务不下载或安装 Skill，也不修改目标项目。

只修改 Prompt 头部允许的产品路径，不修改 installer、文档站、发布清单、测试或文档。

验收标准：有效缓存仍可正常复用；无效或写坏的缓存不会被信任；失败时旧的有效缓存保持原样且公开错误脱敏。
