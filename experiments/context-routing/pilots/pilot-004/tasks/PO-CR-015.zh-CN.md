# 保留任务 PO-CR-015：并发安全且可恢复的观测台缓存

这是一个中风险、本地运行时任务。默认不进入主轮。

加固动态文档观测台的 `.doccache.json`：多个刷新线程可能同时更新不同或相同栏目，启动时也可能遇到上次异常退出留下的损坏缓存。

必须保持这些行为：

- 并发保存不能丢失其他线程已经提交的不同栏目；
- 文件使用 UTF-8 和原子替换，替换失败保留此前有效缓存且清理临时文件；
- 损坏、非对象或结构不合法的缓存不会让服务启动失败，也不会被当成有效栏目数据；
- 缓存路径保持固定在项目本地，调用者不能通过 key 控制文件路径；
- 不改变现有栏目刷新 API、十天过期策略或静态站点生成行为。

只修改 Prompt 头部允许的产品路径，不修改 LLM provider、前端、测试或文档。

验收标准：并发与失败注入下无已提交数据丢失；损坏缓存可恢复；正常缓存行为保持兼容。
