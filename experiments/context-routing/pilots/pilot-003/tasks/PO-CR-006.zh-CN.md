# 任务 PO-CR-006：独立的简体中文 README

这是一个中等风险、多文件公开文档任务。

为仓库新增独立的简体中文 `README.zh-CN.md`，并在英文与中文 README 顶部提供互相可达的语言切换。中文版本应以自然、专业的中文表达当前英文 README 的技术含义，不要把两种语言混在同一篇正文，也不要虚构尚未实现的能力。

必须保持这些规范边界：

- 英文 `README.md` 仍是默认入口，简体中文使用独立文件。
- 两个入口必须互相链接。
- 两种语言对 Seed、ADR、Design、Implementation Plan、State、Validation 与安全采纳边界的含义一致。
- `accepted` 不等于 `implemented`，安装脚手架不等于正式采纳文档权威链。
- 只修改 Prompt 头部列出的两个产品路径，不修改 Skill、模板、测试或实现。

验收标准：

1. 英文和中文介绍位于独立文件，并具有双向语言链接。
2. 两种语言保持相同技术含义与权威边界。
