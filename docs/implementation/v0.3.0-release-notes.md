# Orrery v0.3.0 Release Candidate Notes

Status: release candidate; not yet published. The public v0.2.0 tag, assets, checksum and frozen evidence remain the current public release until the separate promotion and publication phases complete.

## What is included

- A self-contained offline archive containing the Codex Skill compatibility entry, platform-neutral Core/CLI/Observatory source, component versions, the embedded Harness JSON adapter and `LICENSE`.
- One Unified local Observatory entry through `Start Orrery.vbs` or `start-orrery.bat`, with Personal Mode remaining zero-network by default and Team Mode requiring explicit per-project activation.
- Authority Model 1 and operating-rules version 1 contracts, root-only opt-in Authority projection, read-only Workstream Graph and explicit-only legacy graph-layout fallback.
- Exact Git-object packaging: 162 allowlisted entries under `project-orrery/`, fixed ZIP metadata, a ZIP/checksum pair and a deterministic entry receipt bound to the source commit, manifest blob and builder blob.

## Intentionally not included

PyPI/wheel publication, independent Adapter releases, DSH Store, an `orrery` CLI alias, scheduler or automatic deletion, automatic Team Mode enablement, cloud relay and remote/default Authority selection are not part of v0.3.0.

## Release boundary

Building or validating this candidate does not create a tag or GitHub Release. The exact candidate SHA must first pass the required Windows and Ubuntu Promotion checks. Tagging, asset upload and GitHub Release publication remain separate maintainer-authorized actions.
