# Orrery v0.3.0

这一版的重点很简单：**让 Orrery 从“能整理项目文档”，变成一个真正能看懂项目现状、任务关系和多 Agent 协作情况的本地工作台。**

## 你会直接感受到的变化

### 一个入口看完整个项目

启动 Orrery 后，项目总览、文档搜索、文档问答、当前任务、团队协作、任务关系和工作区维护都集中在同一个本地页面里，不需要再打开多个零散工具。

Windows 可以直接运行项目里的 `Start Orrery.vbs` 或 `start-orrery.bat`。

### 任务关系图终于能正常阅读

任务图现在会自动排版，并明确区分：

- 哪些任务是前后接续的；
- 哪些任务互相依赖；
- 哪些任务可能冲突；
- 哪些任务只是同一系列，不代表存在因果关系。

你可以缩放、筛选、收起历史任务并查看关系详情。关系图仍然是只读的，不会因为你点击图表就执行合并、删除或修改任务。

### 能看到当前是谁在推进什么

个人工作台会汇总本机可见的任务和 worktree，区分正在进行、等待确认、历史状态和清理建议。多人、多 Agent 协作时，也能看到任务属于谁、影响哪些模块以及是否存在阻断。

Personal Mode 默认只在本机工作，不访问外部网络。Team Mode 必须由项目明确开启，并且执行请求仍需要成员在自己的机器上确认。

### 文档问答更清楚哪些内容才算事实

Orrery 会把当前事实、已经接受的决定、准备实施的计划和验证结果分开处理，减少“计划写了就被当成已经完成”的情况。

右下角的“问文档”仍然是辅助阅读入口，它不会替你批准决定，也不会把 AI 回答写成项目事实。

### 安装和升级更安全

v0.3.0 提供一个自包含 ZIP，解压后即可离线安装，不依赖 PyPI，也不要求电脑里预先安装 Orrery。

- 新安装默认只创建缺失文件；
- 已有的 `AGENTS.md`、ADR、State、Plan 等作者文档不会被批量覆盖；
- 使用 `--upgrade-tools` 更新 Orrery 托管文件时，会先保存带时间戳的备份；
- 从 v0.2.0 升级不会自动替项目选择或批准新的权威模型。

## 新项目安装

1. 下载 `project-orrery-v0.3.0.zip` 和 `project-orrery-v0.3.0.sha256`。
2. 校验 ZIP。它的 SHA-256 应为：

   `12a7061227cd2f9137dc2923716523059fbc8b528df8b1c7a8cdd8283d7d2385`

3. 解压后先预演安装：

   ```bash
   python project-orrery/scripts/install_project_orrery.py --target <项目目录> --title "项目名称" --dry-run
   ```

4. 确认输出没有问题，再去掉 `--dry-run` 正式安装。
5. 进入项目目录，运行 `Start Orrery.vbs` 或 `start-orrery.bat`。

## 从旧版本升级

先预演托管工具升级：

```bash
python project-orrery/scripts/install_project_orrery.py --target <项目目录> --upgrade-tools --dry-run
```

确认需要替换的文件和备份位置后，再去掉 `--dry-run`。被替换的旧文件会保存在：

`.project-orrery-backup/<时间戳>/`

升级完成后建议运行：

```bash
python project-orrery/scripts/validate_installation.py --target <项目目录>
```

## 这版暂时没有什么

- 没有自动删除 worktree；
- 没有 OS 定时清理任务；
- 没有 `orrery` 命令别名，仍使用 `project-orrery`；
- 没有自动开启 Team Mode；
- 没有云端中继或远程执行；
- Core、CLI 和其他 Adapter 暂未通过 PyPI 独立发布；
- 当前界面仍以中文为主。

如果你只想在本机整理文档、查看任务和理解项目状态，这些限制不会影响主要功能。
