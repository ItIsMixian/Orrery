# Orrery v0.3.1

**Windows 上使用 v0.3.0 的用户应升级到 v0.3.1。** 这一补丁修复了正常启动 Orrery 时可能连续闪现多个命令窗口，以及重复点击启动器会发起第二次 supervisor 启动的问题。

升级后，Windows 默认无界面运行链会统一隐藏 Git 等控制台子进程；如果 Orrery 已经健康运行，再次启动会直接复用相同的进程、端口和本地页面。

## 如何升级

1. 下载 `project-orrery-v0.3.1.zip` 和 `project-orrery-v0.3.1.sha256`。
2. 校验 ZIP 的 SHA-256 与 checksum 文件一致。
3. 解压后先预演托管工具升级：

   ```bash
   python project-orrery/scripts/install_project_orrery.py --target <项目目录> --upgrade-tools --dry-run
   ```

4. 检查替换范围和备份位置，再去掉 `--dry-run` 执行升级。
5. 运行 `python project-orrery/scripts/validate_installation.py --target <项目目录>`，然后重新启动 Orrery。

作者文档不会被批量覆盖；被替换的托管文件仍会先备份到 `.project-orrery-backup/<时间戳>/`。

## 技术说明

- Windows 默认 headless 路径对控制台子进程应用 `CREATE_NO_WINDOW`。
- 正常重复启动会在构建 Observatory 前检查并复用健康 runtime。
- 显式 `--console` 仍保留一个可见 supervisor 控制台、正常错误输出和 Ctrl+C 关闭行为。
- Team Mode、Authority 默认值、schema、DSH Store、`orrery` 别名、scheduler 与自动删除均未改变。

v0.3.0 的 tag 和资产保持原样；本补丁没有替换历史下载内容。
