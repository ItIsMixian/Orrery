# Validation

Validation records reproducible evidence for implementation and documentation claims.

For each validation, record:

- Scope and expected behavior
- Exact command or review procedure
- Environment and important versions
- Result, date, and known gaps

The documentation observatory itself is validated by generating `docs/_site/index.html` and checking that no expected source category is missing.
