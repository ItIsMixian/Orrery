  implemented. Personal Mode remains zero-network.
- Core／CLI remain `unreleased`; public v0.2.0, the user-level Skill, release manifest and verified Adapter
  runtime scopes are unchanged. This Windows Candidate has no W1.1 cross-platform CI evidence yet.
