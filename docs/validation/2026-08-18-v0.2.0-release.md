## CI correction retained as evidence

The first branch run, [32057075492](https://github.com/yw9299-stack/project-orrery/actions/runs/32057075492), failed because `actions/checkout` supplied only a shallow history. Historical benchmark validation therefore could not resolve the corpus commits. Both validation and release workflows now set `fetch-depth: 0`; the subsequent branch and main runs passed on Windows and Ubuntu.

## Known gap

The official GitHub asset and its checksum are internally consistent. A Windows rebuild and the Ubuntu release build contained the same 36 paths, but were not byte-for-byte identical:

- two text files differed by checkout line endings;
- ZIP external permission bits differed across operating systems.

This does not invalidate the official asset checksum, but it means cross-platform reproducible packaging is not yet proven. The next patch should normalize packaged text bytes and assign permissions by a platform-independent allowlist.

## Result

PASS for public release integrity and compatibility publication. PASS does not include cross-platform byte-for-byte archive reproducibility; that limitation is explicitly carried into State and Backlog.
