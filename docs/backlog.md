# Backlog 与影响来源

这里保存尚未被 ADR 接受的方向。

## 高优先级候选

- **跨平台确定性发布包：** 规范化文本行尾和 ZIP 权限位，使 Windows／Linux 从同一 tag 生成完全相同的 archive 与 SHA-256。
- **Context Aperture H2：** 保留风险驱动扩张，但降低 Manifest、Selected Evidence、重复验证和缓存上下文造成的 token 成本。
- **Harness 内容读取证明：** 评估受控文件代理能否记录规范化路径、范围、内容哈希与返回字节，而不形成笨重监控层。
- **原始实验保留策略：** 为仓库外 JSONL、隔离仓库和本机路径定义脱敏、校验和、压缩和过期规则。
- **多人／多 worktree 协作：** 让 State/Manifest 绑定 commit 与 worktree，避免把异步分支状态误写成全局事实。
- **发布与架构工作区边界：** 继续评估维护工作区与公开发行面的分离方式，但不得复制两套产品事实。

## 进入 ADR 前的门槛

- 有清楚的问题陈述和替代方案；
- 有可复现的本地实验或真实项目证据；
- 正确性、安全性和维护成本不劣于当前基线；
- 明确对 State、迁移、兼容性和发布的影响。
