## Product boundary

- The public zip contains only `skills/project-orrery/` content.

## Remaining risks

- Cross-platform archive bytes differ because line endings and ZIP permission metadata are not normalized.

- Raw benchmark evidence remains machine-local pending a retention/export policy.

## Next direction

Return to the context-routing research backlog: define a slimmer H2, design the minimum independent content-read proxy, and fix cross-platform deterministic packaging before the next release.
